# Image credits

All photographic assets in `img/home/` and `img/services/` were generated specifically for Wildlife Match with OpenAI’s built-in image generation tool on August 28, 2026. They are project-owned AI-generated assets and do not use third-party stock photography, external source URLs or hotlinks.

The assets were generated without embedded UI text, logos or watermarks, then locally resized and encoded as WebP for delivery. The service-page variants use distinct local crops and color treatments of project-owned source generations so no page references the same delivery asset.

## Prompt set

The built-in generator was directed to create premium, photorealistic natural/editorial scenes with bright warm daylight and realistic North American homes. The subject set was: peaceful squirrel in a landscaped yard; clapboard exterior wall; robin on a roof; sunlit ivory living room; raccoon outdoors near hydrangeas; protected worker cleaning a bright attic; sealed soffit detail; wildlife tracks beside a foundation; provider inspecting an eave from a ladder; roofline above a flowering garden; displaced soffit vent; empty nesting material at an exterior corner; top-down documentation tools; homeowner photographing a roofline safely from the ground; homeowner/provider exterior conversation; and a distinct squirrel garden for the request form. Every prompt prohibited text, logos, watermarks, traps, cages and fear-based imagery.
