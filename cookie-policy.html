Cookie Policy

This policy describes cookies, local storage and similar browser technologies used by Wildlife Match, including the difference between essential and optional technologies.

Overview

This Cookie Policy applies to the Wildlife Match website operated by Site Operator. It should be read with the Privacy Policy.

The website uses essential session storage and a local-storage preference value. It does not load optional analytics, advertising or behavioral-tracking scripts. Choosing “Allow optional” records the visitor’s preference but does not activate additional scripts.

What cookies and similar technologies are

A cookie is a small text value that a website asks a browser to store and return with later requests. Cookies can support sessions, security, preferences, measurement and advertising. A session cookie generally expires when the browsing session ends; a persistent cookie remains until its expiry date or deletion.

Local storage is a separate browser mechanism that allows a site to store a value on a device without automatically sending it with every web request. Similar technologies may include pixels, software-development kits, tags and device identifiers. This policy uses “browser storage” to refer to these technologies collectively where appropriate.

Essential technologies

Essential technologies support a service explicitly requested by the visitor or are necessary to transmit, secure and operate the website. The current request form relies on a server-side session to help validate submissions and reduce cross-site request forgery and automated abuse.

Because these functions are necessary for the form and site security, blocking essential cookies may cause a submission to fail or may prevent some functions from working correctly. Essential technology is not used by the current site for behavioral advertising.

Optional analytics and advertising

No optional analytics or advertising scripts are currently used. If that changes, this policy will identify each technology, provider, purpose, information involved and duration.

Where applicable law requires consent, non-essential technology must remain disabled until the visitor takes an affirmative action. Rejecting optional technology should be as straightforward as accepting it, and changing a preference should not affect essential site functions.

Examples of technologies that would require review

  • Audience measurement or analytics tools that recognize repeat visits.
  • Advertising pixels, conversion tags or cross-site tracking.
  • Embedded maps, videos, chat tools or social widgets that set third-party cookies.
  • Testing, personalization or call-tracking tools that store identifiers.

Your consent and preference choices

The banner offers “Accept optional” and “Reject optional.” The site stores the selected value in site-cookie-choice. Because optional scripts are not used, both selections currently result in the same technology set: essential storage only.

You can reset the banner by clearing this site’s cookies and local storage in browser settings. If optional technologies are added later, an accessible way to reopen and change preferences will be provided without requiring all browser data to be deleted.

Browser controls

Most browsers allow users to view, delete or block cookies and site data; block third-party cookies; clear data when the browser closes; or use private-browsing modes. Exact controls differ by browser and device.

Deleting the session cookie while completing the request form may invalidate the form session. Deleting site-cookie-choice will cause the preference banner to appear again. Private browsing can limit persistence but does not by itself make browsing anonymous.

Do Not Track and Global Privacy Control

Browsers and extensions may send signals such as Do Not Track or Global Privacy Control. The website does not perform targeted advertising or sale-related tracking and therefore has no optional tracking workflow to disable.

If future technology implicates a legally recognized opt-out signal, the site and its vendors will honor that signal where required and explain the response in this policy.

Third-party content and providers

Following a link to an independent provider or another website takes the visitor to a separate service with its own cookies and policies. Wildlife Match does not control storage set after a visitor leaves this site.

If embedded third-party content is added directly to Wildlife Match, it may allow that third party to receive technical data or set storage. Such content should be assessed and, where necessary, blocked until the visitor consents.

Changes to this policy

This policy may be revised when site functions, hosting, consent controls or applicable requirements change. The updated policy will show a revised date. Material changes to optional tracking or advertising practices should be disclosed before the new technology is activated.
